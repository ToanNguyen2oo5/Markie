## Request, response và dữ liệu nhạy cảm

Đã đối chiếu [OpenAI Moderation guide chính thức](https://developers.openai.com/api/docs/guides/moderation)
trước triển khai: input kết hợp text/image_url, chấp nhận data URL Base64.
Không thay chính sách/category hoặc thêm OCR.

- Cùng bean `moderationRestClient`, API key/model và connect/read timeout hiện có
  (mặc định YAML 2000/5000 ms). Một POST `/v1/moderations`, JSON Content-Type,
  Authorization chỉ Bearer key backend. Không relay JWT/header nội bộ.
- Jackson serialize record `{model,input}`; ảnh dùng input array đúng hai phần:
  `{type:"text",text:content}` và
  `{type:"image_url",image_url:{url:"data:<MIME>;base64,<bytes>"}}`.
  Content giữ nguyên Unicode/whitespace/escape; text-only vẫn gửi input string.
  MIME lấy từ ValidatedImage, không từ tên file/MIME khai báo; không URL localhost.
- Đọc `image.bytes()` đúng một lần mỗi request (defensive copy I03), encode đúng
  bytes đó, không decode pixel/resize/re-encode ảnh. Giới hạn I03 là 5.242.880 B;
  Base64 tối đa 6.990.508 ký tự, cộng prefix MIME. Encoder có mảng Base64 tạm,
  string Base64 tạm và data URL cuối; không cache/field giữ bytes hoặc Base64,
  không gọi accessor nhiều lần. Jackson/transport còn có buffer riêng; không
  tuyên bố tổng RAM chỉ bằng kích thước ảnh hoặc đã stress-test concurrency.
- Cùng parser nghiêm ngặt: results phải array không rỗng; chỉ đọc phần tử đầu;
  flagged bắt buộc boolean. false return; true -> AppException1015/422.
  HTTP không 2xx, timeout/I/O, JSON/content-type sai, thiếu/null/sai kiểu response
  -> ModerationProviderException đã lọc -> AppException1016/503, không cause gốc.
  Không retry/fallback; nhánh1015 nằm ngoài catch provider nên không thành1016.
- Không thêm log dữ liệu/exception. Spring RestClient DEBUG/TRACE gọi toString
  của request; record override thành `ModerationRequest[redacted]`, vẫn giữ
  serialization wire đúng. Test bật TRACE kiểm text/Base64/key/provider body
  và throwable không xuất hiện trong log framework client.
